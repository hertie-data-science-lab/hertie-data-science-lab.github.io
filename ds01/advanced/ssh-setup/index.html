SSH Setup¶

Configuring SSH keys for Git and remote access.

Generate SSH Key¶

ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""

Add to GitHub/GitLab¶

# Display public key
cat ~/.ssh/id_ed25519.pub

# Copy the output

GitHub: - Settings → SSH and GPG keys → New SSH key - Paste and save

GitLab: - Preferences → SSH Keys - Paste and save

Test Connection¶

# GitHub
ssh -T git@github.com

# GitLab
ssh -T git@gitlab.com

SSH Config¶

Create ~/.ssh/config:

Host ds01
    HostName 10.1.23.20
    User <student-id>@students.hertie-school.org
    IdentityFile ~/.ssh/id_ed25519

Usage:

ssh ds01  # Instead of the full format below

Without SSH config:

ssh <student-id>@students.hertie-school.org@10.1.23.20
